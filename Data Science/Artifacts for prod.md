Для продуктовизации модели нужно передать MLOps артефакты. Для этого выполнить чеклист:
- [[apply-script]] - скрипт запусукает инференс на небольшой выборке
- inference sql - в соответствии с [[Train->Inference data pipeline]]
- MLmodel
- test_sample_df.pkl - семпл данных из инференса в формате pd.DataFrame. Нужно для сверки соответствия работы модели в проде и среде разработки
- test_etalon_scores.pkl - эталонные скоры в формате pd.DataFrame. Получены от модели через predict на test_sample_df.pkl
- calibration curve
- roc-auc


1. Создать репозиторий в git
2. Создать страницу в wiki
3. Jupyter Notebook
    1. _apply-script.ipynb - скрипт применения,_ обычно юпитер тетрадка с кодом применения артефактов (модель, токенайзер и тд) и sql для подготовки input_data, имя тетрадки содержит префикс apply_*.ipynb
4. Ссылка на ml flow
    1. _need_info.pkl_ - pickle файл, содержит как правило сериализованный словарь с описанием полей, типами, глубиной тензора и другими специфичными данными, которые используются при инференсе модели
        
    2. _test_sample_df.pkl_ - тестовый сампл данных обычно сериализованный pd.DataFrame (pandas) или pl.DataFrame (polars)
        
    3. _test_etalon_scores.pkl_ - эталонные скоры, которые получил DS на тестовом сампле данных
        
5. Если модель классификации (выявление сегментов):
    1. пороги
    2. калибровочная кривая
6. Для мониторинга
    1. SQL скрипты по сбору фактов и фич для сбора метрик
    2. Пороги для графаны для подсвечивания зеленым и красным
